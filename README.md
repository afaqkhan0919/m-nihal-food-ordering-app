# m-nihal-food-ordering-app

A modern mobile-friendly online food ordering app for M Nihal Fast Food & BBQ.

## Features
- Select food items and choose quantity
- Order summary with live subtotal and total
- Customer details form for name, phone number, and delivery address
- Clear "Place Order" button with validation
- Responsive design for mobile and desktop

## Run locally
1. Open `index.html` in your browser, or
2. Serve the project with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
